## 构建与运行

```bash
cd ~/RM_CV_Homework          # 换成你自己 clone 下来的目录
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4

./build/01_pixels
./build/02_mask
./build/03_detect
```

三个程序会把输出写进 `results/`，同时打印到终端；`assets/` 与 `results/` 的路径通过 CMake 传入的 `PROJECT_ROOT` 宏定位，从任意工作目录运行都可以。`build/` 已加入 `.gitignore`，不需要提交。

### 本次运行的核心结果

在一张 1024×819 的装甲板图像上，用讲义基线参数检出 **1 个装甲板候选**：

```text
轮廓 #0 面积=354.5 L=48.2 W=9.2 L/W=5.24 倾角=2.3°  -> 接受
轮廓 #1 面积=176.0 L=44.2 W=7.2 L/W=6.16 倾角=2.7°  -> 接受
轮廓 #2 点数=4 <5                                    -> 拒绝: 点数不足
轮廓 #3 面积=5.0                                     -> 拒绝: 面积 5.00 < 20
组合 (0,1) 长度比=1.09 |dy|/Lbar=0.19 d/Lbar=2.44 夹角=0.4° 凸=是 -> 接受
四点: 0=(614.5,498.9) 1=(726.8,505.9) 2=(724.9,554.0) 3=(612.4,543.1)
```

其中 `|Δy|/L̄ = 0.19`、`d/L̄ = 2.44` 与讲义主例（原始 1280×1024 帧）**完全一致**，实证了讲义 2.6.1「用平均灯条长度归一化后，比值条件对整体缩放近似不变」；而灯条长度、面积这类绝对量按 0.8 倍缩放，说明面积下限 20、长度下限 6 是尺度相关的。完整对照和原因分析见 `notes/04-第一讲知识整理.md` 第 5 节。

## 基线参数（讲义第 2 章）

| 阶段 | 参数 |
| --- | --- |
| 颜色分数 | 红 `S=max(R−B,0)`；蓝 `S=max(B−R,0)` |
| 掩膜 | `S > 60` 且目标通道 `> 100`，均为严格大于 |
| 形态学 | 3×3 矩形结构元素，**闭运算**（不是开运算） |
| 灯条筛选 | 面积 ≥ 20、L ≥ 6、L/W ≥ 2 且 W>0、倾角 ≤ 35° |
| 配对 | 长度比 ≤ 1.5、`|Δy|/L̄ ≤ 0.35`、`d/L̄ ∈ [0.8,3.2]`、夹角 ≤ 15° |
| 四边形 | 凸且面积 ≥ 1 平方像素 |
| 四点顺序 | 0 左上 / 1 右上 / 2 右下 / 3 左下 |
